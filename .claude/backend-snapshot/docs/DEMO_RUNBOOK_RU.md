# Demo Runbook

## Подготовка (за день до выступления)

- [ ] `docker compose up --build` на машине питчера; smoke: health ready.
- [ ] Прогреть: прогнать `inspect-template` на демо-шаблоне (кэш анализа).
- [ ] Полный прогон на 2 шаблонах: один организаторский + один unseen/public. Артефакты локально.
- [ ] Записать uncut backup-видео полного прогона ≤7 мин.
- [ ] Открыть в браузере: проекты, вкладки демо, PowerPoint с готовой колодой.
- [ ] Отключить уведомления/VPN-задержки; zoom UI 110%; тёмная тема терминала.
- [ ] Проверить provider: рабочий endpoint + env fallback на случай смены токена.

## Сценарий live demo (2 минуты)

| Шаг | Действие | Ожидаемое |
|---|---|---|
| 1 | UI → загрузить unseen template | валидация + анализ начинается |
| 2 | Показать Design DNA панель | палитра, шрифты declared/observed |
| 3 | Запустить generate с canonical content | job queued → stages |
| 4 | Пока идёт — переключиться на готовый run | три варианта, montage |
| 5 | Открыть вариант → PPTX в PowerPoint | подвигать текстовый блок |
| 6 | Audit workspace → выбрать 2 issue → repair | revision 2, diff |
| 7 | Export → скачать PPTX/PDF/HTML + Passport | файлы открываются |

## Fallback-матрица

| Сбой | Реакция |
|---|---|
| Provider недоступен | env-fallback профиль; если и он — показать готовый прогон + сказать прямо |
| SSE оборвался | обновить страницу — state из БД |
| Live >2 мин | перейти к готовому run, вернуться в конце |
| Всё упало | backup-видео без монтажа |

## Запреты во время демо

- Не открывать IDE с кодом (кроме заранее подготовленного `skill/manifest.yaml` если спросят).
- Не показывать токены/`.env`.
- Не запускать «ещё одну генерацию» в конце — хронометраж.
