## ⚙️ Технические требования (подтверждённые в чате)

### Генерация
- **Целевой объём:** 10-15 слайдов (или заданный пользователем)
- **Время генерации одной колоды:** не более **5 минут** (на КАЖДУЮ презентацию отдельно, не на все 3 суммарно)
- **Количество презентаций на проверке:** нужно будет продемонстрировать генерацию **3 презентаций**
- **Отличия между 3 презентациями:** формат и видение отличий — на усмотрение команд. Команды демонстрируют различия, и их актуальность будет оцениваться
- **5 минут отсчёт:** от нажатия кнопки генерации до готового результата

### Модели и инференс
- **LLM модели:** до 35B параметров (опен-сорс, описаны в кейсе)
- **Контракты:** OpenAI compatible ✅
- **Контекстное окно:** ориентироваться на описание модели на HuggingFace
- **LoRA/PEFT-адаптеры:** ❌ НЕ допускается подключение к VK Inference
- **Стек (Python + TS):** рекомендательный, НЕ обязательный — код можно писать на любом языке
- **Изображения:** решение по генерации картинок — на усмотрение команд, ограничения по характеристикам — в кейсе

### Шаблоны
- **Решение НЕ должно быть заточено под 3 предоставленных шаблона**
- На финальной защите презентации генерируются **по шаблону, который команды не видели ранее**

### Входные данные
- На входе используется **только шаблон** (контент-пакета нет)
- Текст для заполнения слайдов **генерируется** исходя из поставленной задачи и контекста

### Время генерации и VK Inference
- Нужно попасть в 5 минут **вне зависимости от инференса VK**
- Нет прямой зависимости — если попадёте по внешнему API в 5 минут, этого достаточно
- По TTFT и SLA VK Inference информации нет
