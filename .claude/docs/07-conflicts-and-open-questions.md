## Допущения, которые мы делаем (зафиксировать в README/ARCHITECTURE)

- Вход демо: 3 шаблона из датасета + один бриф, написанный командой.
- Число слайдов по умолчанию 10–15, иначе — как задал пользователь.
- Язык колоды = язык брифа (скорее всего русский) — AUD-C9.
- «Предзагруженный шаблон»: парсинг может происходить при загрузке, до нажатия «Сгенерировать».
