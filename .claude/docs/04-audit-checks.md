# 04 · Аудит: полный список проверок (ТЗ, Приложение 1)

Приложение 1 — «расширяемый ориентир»: можно расширять и сокращать **с обоснованием** (в `AUDIT.md`).
На защите показать: как устроены проверки, какие **детерминированные**, какие **контекстуальные**.

- **Детерминированная (D):** на одном слайде всегда один результат; опирается на то, что в файле:
  координаты, размеры, коды цветов, ссылки на макеты. → код + тесты.
- **Недетерминированная (N):** про смысл, выполняется моделью, может отличаться между запусками;
  вопросы сформулированы на «да/нет», **вход — картинка слайда** (VLM).

Для недетерминированных: эталонный датасет готовят организаторы + ручная экспертиза (Q&A [28:02]).
Как рендерить слайды в картинки и что делать кодом/VLM — решение команды (Q&A [40:17]).
Как автоисправлять найденное — решение команды (Q&A [40:38]).

## Верификация параметров (все — D)

### Вёрстка
| ID | Проверка | Подсказка по реализации |
|---|---|---|
| AUD-L1 | Элемент вышел за границы слайда | bbox shape vs slide size |
| AUD-L2 | Два блока наложились друг на друга | пересечение bbox (исключая намеренный декор/фон/плейсхолдеры-подложки) |
| AUD-L3 | Текст не поместился в свою рамку | оценка высоты текста по метрикам шрифта (или рендер) vs высота фрейма |
| AUD-L4 | Текст обрезан краем слайда | bbox текста vs границы слайда |
| AUD-L5 | Блоки не выровнены по направляющим макета | сравнение с позициями плейсхолдеров/guides макета, допуск в EMU |
| AUD-L6 | Контент заходит в поля у краёв | поля (safe area), выведенные из шаблона |
| AUD-L7 | Картинка растянута, пропорции нарушены | aspect ratio изображения vs фрейма (учесть crop) |

| AUD-T2 | Кегль не из типографической шкалы шаблона | шкала извлекается из шаблона |
| AUD-T3 | Цвет не из палитры шаблона | цвета run/fill/line/chart vs палитра (theme colors + реально использованные) |
| AUD-T4 | Слайд собран не на макете из шаблона | slide → slideLayout rel принадлежит шаблону |
| AUD-T5 | Логотип или колонтитул сдвинуты с положенного места | позиции vs извлечённые из шаблона |
| AUD-T6 | Контраст текста к фону < 4.5:1 | WCAG, цвет фона: заливка shape → фон слайда/макета/мастера (или пиксели рендера) |

## Требования к UX аудита

- Проблемы **визуализируются** (подсветка bbox на превью слайда, список с severity).
- Пользователь **выбирает**, какие исправить → применяются фиксы → повторный аудит.
- Помечать тип проверки (D/N) и источник (правило/модель) — это спросят на защите.
- Хорошая практика: часть проблем чинить автоматически ещё до показа (переполнение текста,
  выход за границы), с пояснением «что исправлено и почему» (Q&A [41:34]).

## Идеи расширений (обосновать в AUDIT.md, если делаем)

- Проверка, что каждый слайд собран на подходящем по типу макете (титул/раздел/контент).
- Согласованность стилей между 3 вариантами (все соответствуют правилам шаблона — требование ТЗ).
- Число слайдов = запрошенному пользователем.
- Время генерации ≤ 5 мин как «проверка» пайплайна.
- Шрифты embed/доступность в PDF/HTML-экспорте.
