# 02 · Чек-лист требований

Статусы: **MUST** — явно в ТЗ/официальном ответе; **SHOULD** — «будет плюсом» от организаторов;
**MAY** — опционально/на усмотрение. Колонка «Источник» — где подтверждено.
Используй ID в коммитах/PR/доках (напр. `FR-07`) для трассируемости.
