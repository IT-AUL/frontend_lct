## Объём и рамки

| Вопрос | Ответ | Для нас |
|---|---|---|
| Свои идеи/фичи сверх ТЗ — плюс? [14:58], [16:08] | Плюс, если обоснованы и работают на основную цель (не «корпоративный мессенджер»). Сначала ТЗ, потом сверху. | Сначала закрыть все MUST. Любая фича — с обоснованием на питче. |
| Есть свои входные артефакты для проверки? [17:28] | Всё в ТЗ. Особый запрос: **красиво и аккуратно показывать числовые данные**, строить полезные графики. | Графики из данных — приоритетная визуализация. |
| Версионирование скиллов/агентов — что это? [19:07] | Если скилл/конфиг агента изменился — видно, что результат генерации изменился из-за новой версии. Многопользовательская работа: изменения одного влияют на других. Суть: **аудит, прослеживаемость, влияние на результат**. | Хранить версию (хэш/semver) каждого промпта/скилла; писать в метаданные результата; показывать в UI. |
| Минимум по версионированию? [45:47] офиц. | Промпты и конфиги скиллов/агентов **отдельными файлами** + **Git**. Переключение/откат через UI не требуется, но плюс. | MUST: файлы + git. SHOULD: версия в результате. MAY: UI отката. |
